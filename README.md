## 阅读方式

- **第一次学**：顺着每篇的核心概念和操作流程阅读。
- **需要推导**：展开文中的折叠部分，查看接线、时序和机制。
- **快速复习**：直接看“易错点”和“口述版本”。

具体地址、引脚和时序以所用芯片、屏幕控制器的数据手册为准。每篇末尾附有原始资料链接。
