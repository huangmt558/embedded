# SPI 通信

[返回目录](../README.md)

**SPI 是同步串行通信接口：主机提供时钟，数据按位传输。常见四线配置支持全双工，主机发送与接收可以同时进行。**

本文以 **STM32F103 作为主机、双线全双工、8 位数据帧、先传高位、低电平有效的独立 CS** 为例。这里的“双线”指 MOSI、MISO 两条数据线，不包含时钟和片选。

## 1. 四根线各管什么

| 信号线 | 含义 | 信号方向 |
| --- | --- | --- |
| SCK／SCLK | 时钟，提供数据传输节拍 | 主机 → 从机 |
| MOSI | Master Out Slave In，主发从收 | 主机 → 从机 |
| MISO | Master In Slave Out，主收从发 | 从机 → 主机 |
| CS／SS／NSS | 片选，选择本次通信的从机 | 主机 → 从机 |

本例中，CS 拉低选中，拉高取消选中；外部从机的 CS 可以由主机的普通 GPIO 输出控制。具体电平和时序按从机手册确定。[RM0008：SPI 功能说明][rm0008]

## 2. 全双工：一个字节怎样同时收发

**全双工表示两边各自的数据可以同时传输。**一个 SCK 周期，在每个方向传输一位；8 位数据帧共用 8 个 SCK 周期。

假设传输前，主机准备发送 `0x01`，从机准备发送 `0xA5`：

```text
             同一组 8 个 SCK 周期
主机 ───────── 0x01 ─────────→ 从机
主机 ←──────── 0xA5 ────────── 从机
```

传输结束后，**从机收到 0x01，主机收到 0xA5**。两条数据线传的是各自准备的数据。[RM0008：全双工通信][rm0008]

<details>
<summary>展开看 8 个时钟周期里，每次传哪一位</summary>

本例先传高位：

- 主机发送 `0x01 = 00000001`。
- 从机发送 `0xA5 = 10100101`。

| 第几个 SCK 周期 | MOSI：主机发出 | MISO：主机收到 |
| ---: | ---: | ---: |
| 1 | 0 | 1 |
| 2 | 0 | 0 |
| 3 | 0 | 1 |
| 4 | 0 | 0 |
| 5 | 0 | 0 |
| 6 | 0 | 1 |
| 7 | 0 | 0 |
| 8 | 1 | 1 |

**收发同时进行，共用 8 个时钟周期。**每个完整时钟周期包含上升沿和下降沿，不能把两个边沿各算成一个完整周期。

</details>

### 从机会把刚收到的字节原样发回来吗

**SPI 没有自动回显的通用规则。**主机发送 `0x01`，不代表从机就会返回 `0x01`。返回什么，由从机准备的数据及其通信协议决定。

如果要求从机先完整收到一个字节，再把这个字节回传，就需要从机程序安排，并由主机继续提供后续传输的时钟。不要把“同时收发”理解成“收到完整字节后，在原来的 8 个时钟里再发回”。

## 3. 只想接收，为什么还要发送占位字节

**从机发回数据也需要时钟，而 SCK 由主机产生。**

在本文的 STM32 全双工主机配置下，发起一次字节发送，会让 SPI 硬件产生相应的时钟。即使主机没有业务数据要发，也可以发送占位数据，以接收从机发回的数据。[ST 官方 F1 HAL 驱动][hal-spi]

例如，从机已经准备好返回 `0x01`：

```text
主机发送占位字节 0xFF
          ↓
SPI 硬件产生 8 个 SCK 周期
          ↓
MOSI：主机发出 11111111（0xFF）
MISO：主机收到 00000001（0x01）
```

主机这时关心的是收到的 `0x01`。发出的 `0xFF` 用来启动传输、提供时钟，所以叫占位字节。

**占位值不一定是 0xFF，发什么应按从机协议确定。**也不是“发送什么就收到什么”。

只计算数据阶段、每字节 8 位时：

| 接收字节数 | 需要的 SCK 周期数 |
| ---: | ---: |
| 1 | 8 |
| 3 | 24 |

<details>
<summary>有接收函数，为什么还说要发送？收到的每个字节都有用吗？</summary>

F1 HAL 的 `HAL_SPI_Receive` 在主机、双线全双工配置下，会转入收发函数，通过发送占位数据产生时钟。软件接口叫“接收”，底层仍可以同时执行发送。[HAL_SPI_Receive 实现][hal-spi]

对普通 8 位全双工数据帧，每发送一字节，接收侧也会移入一字节；但这一字节是否是有效业务数据，由从机协议和当前传输阶段决定。例如发送命令时收到的字节可能需要丢弃，后续数据阶段收到的字节才是需要的内容。

本文讨论的是全双工主机配置，不把“软件必须发送占位字节”推广到所有 SPI 外设的所有接收模式。

</details>

## 4. CPOL、CPHA 分别控制什么

| 参数 | 设置为 0 | 设置为 1 |
| --- | --- | --- |
| CPOL：时钟极性 | SCK 空闲时为低电平 | SCK 空闲时为高电平 |
| CPHA：时钟相位 | 第一个边沿采样 | 第二个边沿采样 |

**采样**就是接收端读取数据线上当前的 `0` 或 `1`。发送端在另一个边沿更新数据，使接收端采样时数据稳定。CPHA 应按“采样边沿”来定义，避免把采样和改变数据混淆。[RM0008：时钟相位与极性][rm0008]

### 第一个边沿究竟是哪个边沿

“第一个边沿”指 SCK **离开空闲电平的第一次跳变**，“第二个边沿”则回到空闲电平：

| CPOL | 空闲电平 | 第一个边沿 | 第二个边沿 |
| ---: | --- | --- | --- |
| 0 | 低 | 上升沿 | 下降沿 |
| 1 | 高 | 下降沿 | 上升沿 |

所以，`CPOL = 1、CPHA = 0` 表示：空闲为高，在第一个边沿，也就是**下降沿采样**。

<details>
<summary>展开四种常见 SPI 模式</summary>

| 模式 | CPOL | CPHA | 空闲电平 | 采样边沿 | 改变数据的边沿 |
| ---: | ---: | ---: | --- | --- | --- |
| 0 | 0 | 0 | 低 | 上升沿 | 下降沿 |
| 1 | 0 | 1 | 低 | 下降沿 | 上升沿 |
| 2 | 1 | 0 | 高 | 下降沿 | 上升沿 |
| 3 | 1 | 1 | 高 | 上升沿 | 下降沿 |

CPHA 为 0 时，第一位数据必须在第一个采样边沿之前准备好；表中的“改变数据的边沿”主要描述传输进行时后续数据的更新。

主从双方的时序模式必须匹配，具体选择以从机手册为准。

</details>

## 5. 一个主机怎样选择多个从机

在常见的独立片选连接中，SCK、MOSI、MISO 可以共用，**每个从机各有一根独立的 CS**，分别连接主机 GPIO。[Microchip：SPI 总线连接][spi-bus]

```text
主机 GPIO_A ──→ 从机 A 的 CS
主机 GPIO_B ──→ 从机 B 的 CS
```

以两个低电平有效的 CS 为例：

| 通信对象 | CS_A | CS_B |
| --- | --- | --- |
| 都不选 | 高 | 高 |
| 选择从机 A | 低 | 高 |
| 选择从机 B | 高 | 低 |

因此，“GPIO 输出低电平选中”是对的，还应补充：**只拉低目标从机的 CS，其他从机保持未选中。**

共享 MISO 的前提是未选中的从机释放 MISO，使其处于高阻状态。常规读通信中避免同时选中多个从机，否则多个输出可能争用同一根 MISO。[TI：SPI 通信基础][ti-spi]

<details>
<summary>GPIO 控制 CS 与 STM32 的内部 NSS 管理是什么关系？</summary>

外部 CS 用 GPIO 控制，与 SPI 外设内部如何管理 NSS，是两个相关的配置项。采用软件控制 CS 的主机方案时，通常也要选择合适的软件 NSS 管理配置；不能只把某个 GPIO 设为输出，就认为 SPI 外设已经配置完成。

具体使用哪个 GPIO、怎样初始化 SPI，按所用芯片、引脚复用和库配置处理。[RM0008：NSS 管理][rm0008]

</details>

## 6. 易错点

| 容易混淆的说法 | 准确理解 |
| --- | --- |
| 从机有数据，就自己产生 SCK 发给主机 | 本文的主从关系中，SCK 由主机提供 |
| 主机发 0x01，从机就自动回 0x01 | 两条数据线各传各自准备的数据 |
| 全双工同时发送和接收一字节，需要 16 个时钟 | 同一全双工数据帧的两个方向共用 8 个时钟 |
| 占位字节必须是 0xFF | 占位值按从机协议确定 |
| CPOL 表示高电平还是低电平启动 | CPOL 定义 SCK 的空闲电平 |
| CPHA 定义在哪个边沿写数据 | 通常按第一个或第二个边沿采样来定义 |
| CPHA = 0 就一定是上升沿采样 | 还要结合 CPOL；CPOL = 1 时是下降沿 |
| 两个从机共接一根 CS，也能分别选中 | 常见独立片选方案中，每个从机分别控制 CS |

## 7. 口述版本

> SPI 是同步串行通信接口。主机通过 SCK 提供时钟，MOSI 主发从收，MISO 主收从发，CS 选择从机。常见四线配置支持全双工，一个 8 位数据帧的发送与接收共用 8 个时钟周期，两边传输的是各自准备的数据。全双工主机读取数据时，可以发送占位字节来产生时钟。CPOL 决定时钟空闲电平，CPHA 决定在第一个还是第二个边沿采样。连接多个从机时，常见做法是共用时钟和数据线，分别用独立 CS 选择从机。
