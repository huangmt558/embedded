# ADC 模数转换

[返回目录](../README.md)

**ADC 把模拟电压转换成数字值。分辨率决定数字值的等级数，实际测量精度还受参考电压、噪声和电路等因素影响。**

本文以 **STM32F103C8T6、12 位 ADC、普通规则通道组**为例，结合 [定时器](timers-pwm.md) 和 [DMA](dma-uart-reception.md) 理解周期采样。

## 1. ADC 转换的是什么

ADC 是**模数转换器**（Analog-to-Digital Converter）；DAC 才是数模转换器。

以模拟输出的光敏传感器为例：

```text
光照变化 → 传感器输出电压变化 → ADC 转换 → 数字值
```

ADC 直接转换的是输入电压；要得到具体光照强度，还需要根据传感器特性和电路换算。

## 2. 12 位、参考电压和精度

12 位 ADC 有 `2¹² = 4096` 个数字等级，输出值为 `0～4095`。

假设参考电压范围为 `0～3.3 V`：

```text
理想量化步距 = 3.3 V / 4096
             ≈ 0.000806 V
             = 0.806 mV
```

输入电压为 `1.65 V`，约为参考电压的一半，理想结果约为 `2048`。

**0.806 mV 是理想步距，不代表每次测量误差一定小于 0.806 mV。**实际结果还受到参考电压、ADC 本身、电路噪声和传感器误差等影响。[ST：提高 ADC 测量精度][accuracy]

## 3. 单次、连续和多通道扫描

| 方式 | 工作过程 |
| --- | --- |
| 单次转换 | 单通道时每次触发启动一次转换；再次转换需要再次触发，不一定重新初始化 |
| 连续转换 | 第一次启动后，ADC 自动重复转换，直到停止或改变配置 |
| 多通道扫描 | 单个 ADC 按配置的顺序逐个转换多个通道 |

例如扫描顺序配置为 `通道 3 → 通道 1 → 通道 5`，DMA 从数组开头依次保存时：

```text
adc_buf[0] ← 通道 3
adc_buf[1] ← 通道 1
adc_buf[2] ← 通道 5
```

**单个 ADC 的扫描顺序由配置决定**，不一定按通道号从小到大，也不是三个通道在同一时刻完成转换。[RM0008：ADC 规则通道扫描][rm0008]

## 4. 定时器、ADC 和 DMA 怎样配合

需要周期采样时，可以选择 ADC 支持的定时器事件作为硬件触发源：

```text
定时器每 10 ms 产生触发事件
                 ↓
ADC 完成一次转换，或按配置完成一轮扫描
                 ↓
DMA 逐个搬运转换结果到 RAM
```

例如 ADC1 配置为**非连续、扫描 3 个规则通道、间断模式关闭**，每次触发前上一轮已经完成：

- 每次触发执行一轮扫描，得到 **3 个转换结果**，DMA 分别搬运。
- 每 10 ms 一轮，即每秒 **100 轮**。
- 每个通道每秒采样 **100 次**；三个通道合计 **300 次转换/秒**。

定时器事件可直接通过硬件触发 ADC；也可以使用定时器中断，在回调中由软件启动。具体可选触发源以 F103 的参考手册为准。[ST 数据手册][datasheet]

<details>
<summary>为什么连续转换不等于每 10 ms 只采一个值？</summary>

开启连续转换后，第一次触发启动 ADC，之后 ADC 自动继续转换。

在 ADC1 规则通道的 DMA 请求已开启、DMA 仍能接收请求时，转换结果会随 ADC 转换陆续被搬运，不是只在定时器每 10 ms 触发时搬运。DMA 普通模式达到设定数量后停止，循环模式可继续搬运。

如果希望每 10 ms 触发一次单通道转换，可关闭连续转换，使用支持的定时器事件重复触发；配置时还要确保每次触发前上一次转换已结束。

</details>

## 5. ADC 时钟、采样时间和转换时间

F103 的 ADC 时钟由 PCLK2 经预分频得到，最高 **14 MHz**。[ST 数据手册][datasheet]

例如 `PCLK2 = 72 MHz`：

| ADC 分频 | ADC 时钟 | 是否符合 14 MHz 上限 |
| ---: | ---: | --- |
| 4 | 18 MHz | 不符合 |
| 6 | 12 MHz | 符合 |
| 8 | 9 MHz | 符合 |

在这些选项中，6 分频得到不超过上限的较快 ADC 时钟。

ADC 采样时需要让内部采样电容的电压接近输入电压。信号源输出阻抗较高时，采样时间过短可能导致电容未充分稳定，从而产生偏差。采样时间更长会增加一次转换的总时间，降低可达到的最高连续采样速度。[ST ADC 测量建议][accuracy]

F103 一次转换的总周期数：

```text
总转换周期 = 采样周期 + 12.5 个 ADC 时钟周期
```

例如 ADC 时钟 `12 MHz`、采样时间 `1.5 个周期`：

```text
总转换周期 = 1.5 + 12.5 = 14 个周期
转换时间 = 14 / 12 MHz ≈ 1.17 μs
```

## 6. 校准能解决什么

温度变化确实会影响测量。F103 内置的 ADC 自校准主要减小**内部电容阵列差异**引起的误差；ST 建议上电后进行校准。校准完成后再进行正常转换。[RM0008：ADC 校准][rm0008]

校准不能保证消除所有温漂、参考电压、噪声或外部传感器带来的误差。**分辨率、校准和最终测量精度要分开理解。**

## 7. 易错点

| 容易混淆的说法 | 准确理解 |
| --- | --- |
| ADC 是数模转换器 | ADC 是模数转换器；DAC 才是数模转换器 |
| 12 位最大值是 4096 | 共有 4096 个等级，数值范围是 0～4095 |
| 理论步距 0.806 mV，误差一定小于它 | 实际精度还受参考电压、噪声等因素影响 |
| 单次转换后再次采样必须重新初始化 | 再次触发即可，具体触发方式按配置确定 |
| 单个 ADC 扫描多个通道时同时转换 | 按配置的通道顺序逐个转换 |
| 连续转换时 DMA 只在定时器触发时搬运 | DMA 按 ADC 的转换请求搬运，取决于配置和 DMA 模式 |
| 采样时间越短越准确 | 采样时间不足可能让输入尚未稳定，产生偏差 |
| 校准能消除所有温漂和外部误差 | 自校准主要减小 ADC 内部电容阵列差异引起的误差 |

## 8. 口述版本

> ADC 把模拟电压转换成数字量。F103 的 12 位 ADC 有 4096 个等级，范围为 0～4095；参考范围 0～3.3 V 时，理想步距约为 0.806 mV。单通道单次模式每次触发一次，连续模式启动后自动重复；单个 ADC 的多通道扫描按配置顺序逐个进行。定时器可以触发 ADC，DMA 再把结果搬到 RAM。ADC 时钟不能超过芯片规定的上限，采样时间要考虑信号源；上电后进行自校准可减小内部电容阵列差异带来的误差。
