# 定时器与 PWM

[返回目录](../README.md)

**定时器靠时钟节拍计数；配置并启动后，PWM 由硬件自动输出。PSC、ARR 决定周期，CCR 决定占空比。**

本文以 **STM32F103 的 TIM2、内部时钟、连续向上计数、边沿对齐、PWM 模式 1、高电平有效**为例。下列公式均按这个条件使用，并假定配置值已经生效。

## 1. 四个寄存器分别管什么

| 寄存器 | 名称 | 主要作用 |
| --- | --- | --- |
| PSC | 预分频器 | 把输入时钟按 `PSC + 1` 分频，决定计数节拍 |
| CNT | 计数器 | 保存当前计数值，每来一个计数节拍加 1 |
| ARR | 自动重装载寄存器 | 在向上计数时决定计数上限，进而决定周期 |
| CCRx | 捕获/比较寄存器 | PWM 时与 CNT 比较，决定通道有效的时间；x 是通道编号 |

`CCR` 本身不计数。在输入捕获模式下，它用于保存捕获时刻的 CNT 值；在输出比较和 PWM 模式下，它提供比较值。[RM0008：通用定时器][rm0008]

```text
定时器输入时钟 f_TIM → PSC 分频 → CNT 计数
                                  ├─ 配合 ARR：决定一个周期有多长
                                  └─ 与 CCR 比较：控制 PWM 通道输出
```

正常连续向上计数时，CNT 的序列是：

```text
0 → 1 → 2 → …… → ARR → 0 → 1 → ……
```

从 `ARR` 回到 `0` 的溢出时刻，在允许更新的配置下产生更新事件 UEV。**只是计到 ARR，还要再经过一个计数节拍才回到 0。**

更新事件不等于 CPU 一定执行中断；还需要更新中断使能、NVIC 和 CPU 响应条件允许。可联系 [中断与轮询](interrupts-nvic-exti.md) 理解。[RM0008：时基单元][rm0008]

## 2. 怎样计算计数时间、周期和 PWM 频率

`f_TIM` 表示 **PSC 分频之前的定时器输入时钟频率**。

**计算思路：每秒能数多少次 ÷ 每个周期需要数多少次 = 每秒的周期数。**

```text
计数频率 f_CNT = f_TIM / (PSC + 1)
一个计数节拍的时间 = 1 / f_CNT

一个周期的计数节拍数 = ARR + 1
PWM 频率 f_PWM = f_CNT / (ARR + 1)
              = f_TIM / [(PSC + 1) × (ARR + 1)]

周期 T = 1 / f_PWM
       = (PSC + 1) × (ARR + 1) / f_TIM
```

为什么有 `+1`：分频系数是 `PSC + 1`，而 CNT 从 `0` 数到 `ARR`，包含首尾共 `ARR + 1` 个值。[RM0008：预分频器与计数模式][rm0008]

### 怎样一步步算出 1 kHz

给定 `f_TIM = 72 MHz`、`PSC = 71`、`ARR = 999`：

| 步骤 | 计算 | 含义 |
| --- | --- | --- |
| 1. 先算计数速度 | `72 MHz ÷ (71 + 1) = 1 MHz` | 每秒计数 100 万次，每个节拍 1 μs |
| 2. 再算每周期的节拍数 | `999 + 1 = 1000` | CNT 从 0 数到 999，每周期需要 1000 个节拍 |
| 3. 算每秒的周期数 | `1000000 ÷ 1000 = 1000 Hz = 1 kHz` | 每秒重复 1000 个完整的 PWM 周期 |

所以 `PWM 频率 = 1 kHz`，`周期 = 1 / 1000 s = 1 ms`。

### 保持计数速度不变，改变 ARR

仍令 `f_TIM = 72 MHz`、`PSC = 71`，计数频率就是 `1 MHz`：

| ARR | 每周期的计数节拍数 | 周期 | 频率 |
| ---: | ---: | ---: | ---: |
| 999 | 1000 | 1 ms | 1 kHz |
| 9999 | 10000 | 10 ms | 100 Hz |

**1 MHz 表示每秒计数一百万次，每次数 1 μs；不是每次数 1 ms。**

<details>
<summary>定时器输入时钟一定等于 CPU 或 APB 时钟吗？</summary>

不一定。F103 的 TIM2 挂在 APB1：

- APB1 分频系数为 1 时，`f_TIM2 = PCLK1`。
- APB1 分频系数大于 1 时，`f_TIM2 = 2 × PCLK1`。

例如常见配置中，HCLK 为 72 MHz，APB1 二分频，PCLK1 为 36 MHz，但 TIM2 的输入时钟为 72 MHz。题目直接给定定时器输入时钟时，就从这个值开始计算。[RM0008：RCC 时钟树][rm0008]

</details>

## 3. 周期、频率、占空比是什么

PWM 是 **脉宽调制（Pulse Width Modulation）**。常见用法是在周期保持不变时，改变脉冲宽度，从而改变占空比。

| 概念 | 定义 | 例子 |
| --- | --- | --- |
| 周期 T | 一个完整波形重复一次所用的时间 | 1 ms |
| 频率 f | 每秒重复的完整周期数，`f = 1/T` | 1 kHz，即每秒 1000 个周期 |
| 占空比 D | 本文指高电平时间占整个周期的比例 | 高电平 250 μs、周期 1 ms，则 D = 25% |

```text
占空比 D = 高电平时间 / 整个周期 × 100%
```

**频率按完整周期计数，不能把上升沿和下降沿各算一个周期。**高电平时间与整个周期之比为 `1∶4`，占空比就是 `25%`。

若高电平点亮 LED，增大高电平占空比会增加每周期内的点亮时间，通常会让人感觉更亮；若低电平点亮，关系相反。

## 4. CCR 怎样控制 PWM

在本文的 **向上计数、PWM 模式 1、高电平有效**条件下：

```text
CNT < CCR：输出高电平
CNT ≥ CCR：输出低电平
```

因此，在正常的占空比设置范围内：

```text
PWM 频率 = f_TIM / [(PSC + 1) × (ARR + 1)]
高电平时间 = CCR / f_CNT
占空比 D = CCR / (ARR + 1) × 100%
```

输出条件来自定时器的比较逻辑；改变极性、PWM 模式或计数方式后，应重新确认关系。[RM0008：PWM 模式][rm0008]

### 固定周期，只改变 CCR

沿用 `f_TIM = 72 MHz`、`PSC = 71`、`ARR = 999`，周期固定为 `1 ms`：

| CCR | 高电平对应的 CNT | 高电平时间 | 占空比 |
| ---: | --- | ---: | ---: |
| 0 | 无 | 0 | 0% |
| 250 | 0～249 | 250 μs | 25% |
| 750 | 0～749 | 750 μs | 75% |
| 1000 | 0～999，整个周期 | 1 ms | 100% |

这里 `CCR = 1000` 可由寄存器表示，且大于 `ARR = 999`，所以一直满足 `CNT < CCR`。

**只把 CCR 从 250 改成 750，频率仍为 1 kHz，占空比从 25% 变为 75%。**如果改变 ARR 而保持 CCR 不变，周期和占空比一般都会改变。

<details>
<summary>写入新的 PSC、ARR、CCR 后，为什么可能不是立刻生效？</summary>

PSC 有缓冲机制，新分频值在更新事件时装入生效。ARR 和 CCR 也可启用预装载：软件先写入新值，再在更新事件时转入实际工作的寄存器。

这样可以在周期边界统一更新，减少在周期中途改变比较值带来的波形异常。初始化时常通过 UG 产生更新事件，让预分频等配置先装入；具体按所用库和寄存器配置处理。[AN4776：预装载机制][an4776]

</details>

## 5. 输出 PWM 需要每周期进入中断吗

**不需要。**CPU 配好时钟、计数参数、PWM 模式、输出极性、GPIO 复用和通道使能，并启动定时器后，硬件会持续完成计数、比较和输出。

```text
CPU 配置并启动
    ↓
定时器硬件：计数 → 比较 → 输出高低电平 → 重复
    ↓
CPU 可以执行其他任务
```

中断可以用来通知软件发生了更新或比较事件，但**产生 PWM 波形本身不依赖中断服务函数**。[RM0008：PWM 模式][rm0008]

CPU 进入低功耗状态后是否仍能输出，还要看相应模式是否保留定时器及其时钟，不能从“硬件自动输出”直接推导为所有低功耗模式都能工作。

## 6. 易错点

| 容易混淆的说法 | 准确理解 |
| --- | --- |
| ARR 是捕获/比较寄存器 | ARR 是自动重装载寄存器；CCR 才是捕获/比较寄存器 |
| CCR 自己计数，计到 ARR 后溢出 | CNT 计数；CCR 提供比较值 |
| 写 PSC = 71，就是 71 分频 | 实际是 72 分频 |
| ARR = 999，一个周期有 999 个节拍 | 从 0 开始，共 1000 个节拍 |
| 比较事件就是更新事件 | 比较事件与 CNT、CCR 匹配有关；更新事件还涉及溢出、软件 UG 等来源 |
| 改占空比一定会改频率 | PSC、ARR 不变时，只改 CCR 不改变 PWM 频率 |
| PWM 必须靠中断翻转 GPIO | 定时器硬件能自动输出 PWM |

## 7. 口述版本

> 定时器通过时钟节拍计数。PSC 对输入时钟进行 PSC 加一分频，CNT 保存当前计数值，ARR 决定向上计数的上限。一个周期包含（ARR＋1）个计数节拍，PWM 频率就是每秒计数次数除以每周期计数次数。PWM 模式 1、高电平有效时，CNT 小于 CCR 就输出高电平，否则输出低电平。因此，PSC 和 ARR 决定周期，CCR 决定占空比。配置并启动后，硬件会自动输出，不需要 CPU 每个周期进入中断。
